A one-line office joke, written by a small deterministic Python program. The boss said to treat the company like family — the program writes exactly what that means after 6 pm to `/output/entry.txt` (96 characters, UTF-8, single line).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
